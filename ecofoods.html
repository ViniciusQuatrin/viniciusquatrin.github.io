Case Study

EcoFoods

Revitalização e Integração de Ecossistema de Pagamentos para PDV Móvel

O Desafio

O aplicativo original apresentava uma estrutura de código rígida, UI defasada e sérios problemas de escalabilidade. O maior gargalo técnico era a ausência de uma integração padronizada com terminais de pagamento (SmartPOS), exigindo um esforço manual imenso para suportar diferentes adquirentes como Cielo, Getnet e Gertec.

Kotlin Android SDK Jetpack Compose MVVM Build Flavors

A Solução Técnica

Implementei uma refatoração profunda focada em modularização e separação de interesses:

  • • Arquitetura de Pagamentos: Utilizei Build Flavors para isolar as implementações específicas de cada SDK de maquininha de cartão. Isso permitiu que o mesmo core de aplicação funcionasse em hardware distinto de forma transparente.
  • • Concorrência e Performance: Refatorei o processamento de dados para utilizar Kotlin Coroutines, gerenciando Dispatchers para evitar bloqueios na UI e tratar corridas críticas em transações.
  • • Modern UI: Iniciei a migração de layouts legados em XML para Jetpack Compose, resultando em um código de interface mais declarativo, conciso e fácil de manter.

Impacto e Resultados

  • Melhoria de Performance: Redução notável na latência de resposta do app e maior fluidez na navegação.
  • Consistência Visual: Nova interface alinhada a padrões modernos de UX, aprovada em testes internos.
  • Escalabilidade de Hardware: Capacidade de deploy para terminais Sicoob, Getnet, Gertec e Cielo a partir de uma base de código unificada.
  • Manutenibilidade: Código mais limpo seguindo MVVM estrito, facilitando a entrada de novos desenvolvedores no projeto.
