Modernización de Software Legado e Integración de Hardware Periférico

El Desafío

El sistema contaba con una base de código de más de 11 años, escrita íntegramente en Java. Con la evolución del ecosistema Android y las nuevas exigencias de Google Play Store, la aplicación enfrentaba diversos métodos obsoletos y riesgos reales de fallos en versiones recientes del sistema operativo. El reto consistía en modernizar sin alterar la interfaz consolidada para no impactar en la familiaridad del usuario.

Kotlin Java Legacy Python (Automation) View Binding Hardware Integration

La Solución Técnica

  • • Refactorización Automatizada: Para acelerar la transición de un proyecto de gran escala, desarrollé un script en Python para automatizar la sustitución masiva de findViewById por View Binding, reduciendo drásticamente o error humano y los tiempos de migración.
  • • Migración Java a Kotlin: Implementé la conversión gradual y segura de clases críticas de negocio a Kotlin, garantizando la resolución de errores de nulidad inherentes a la base antigua.
  • • Integración Periférica: Desarrollé el módulo de comunicación vía Protocolo de Impresión para impresoras portátiles, permitiendo la emisión inmediata de pedidos, facturas y recibos en campo.

Impacto y Resultados

  • Extensión de Vida Útil: El software fue totalmente adecuado a las exigencias modernas del SDK de Google, garantizando más años en el mercado.
  • Estabilidad Operativa: Corrección masiva de errores latentes y mejora en la robustez del código a través del sistema de tipos de Kotlin.
  • Funcionalidad Crítica: La integración con impresoras permitió que la fuerza de ventas operara de forma totalmente independiente y móvil.
  • Deuda Técnica Reducida: Eliminación de componentes heredados y código obsoleto, facilitando mantenimientos futuros.
