Modernización Web

Hflex

Transición de Sistemas Desktop a BI y Seguimiento Web

El Desafío

Intelitech poseía sistemas desktop robustos, pero sentía la necesidad de ofrecer a los clientes una forma de seguir los datos de sus empresas desde cualquier lugar. El reto consistía en crear un puente entre los datos locales (desktop) y un portal web moderno para la toma de decisiones.

Ruby on Rails PostgreSQL Business Intelligence Legacy Integration

La Solución Técnica

  • • Arquitectura Web: Estructuración del backend utilizando Ruby on Rails, aprovechando la agilidad del framework para crear un sistema de portal web seguro y reactivo.
  • • Integración de Datos: Creación de rutinas de sincronización e integración para que los datos generados en los sistemas desktop se procesaran y estuvieran disponibles dinámicamente en la plataforma Hflex.
  • • Modelado de Datos: Implementación de una estructura de base de datos optimizada en PostgreSQL para soportar consultas rápidas de indicadores de gestión.

Impacto

El proyecto representó el primer paso de la empresa hacia soluciones 100% web, creando la infraestructura necesaria para que las próximas generaciones de productos pudieran coexistir en múltiples entornos (Desktop y Web).
