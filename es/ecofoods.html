Case Study

EcoFoods

Revitalización e Integración del Ecosistema de Pagos para PDV Móvil

El Desafío

La aplicación original presentaba una estructura de código rígida, interfaz de usuario obsoleta y graves problemas de escalabilidad. El mayor cuello de botella técnico era la falta de una integración estandarizada con terminales de pago (SmartPOS), lo que requería un inmenso esfuerzo manual para soportar diferentes adquirentes como Cielo, Getnet y Gertec.

Kotlin Android SDK Jetpack Compose MVVM Build Flavors

La Solución Técnica

Implementé una refactorización profunda enfocada en la modularización e independencia de componentes:

  • • Arquitectura de Pagos: Utilicé Build Flavors para aislar las implementaciones específicas de cada SDK de terminal bancário. Esto permitió que el mismo núcleo de la aplicación funcionara en hardware distinto de forma transparente.
  • • Concurrencia y Rendimiento: Refactoricé el procesamiento de datos para utilizar Kotlin Coroutines, gestionando Dispatchers para evitar bloqueos en la interfaz y manejar condiciones de carrera críticas en las transacciones.
  • • Interfaz Moderna: Inicié la migración de diseños heredados en XML a Jetpack Compose, resultando en un código de interfaz declarativo, conciso y fácil de mantener.

Impacto y Resultados

  • Mejora del Rendimiento: Reducción notable en la latencia de respuesta de la aplicación y navegación más fluida.
  • Consistencia Visual: Nueva interfaz alineada con los estándares modernos de UX, aprobada en pruebas internas.
  • Escalabilidad de Hardware: Capacidad de despliegue en terminales Sicoob, Getnet, Gertec y Cielo desde una base de código unificada.
  • Mantenibilidad: Código más limpio siguiendo un patrón MVVM estricto, facilitando la incorporación de nuevos desarrolladores al proyecto.
