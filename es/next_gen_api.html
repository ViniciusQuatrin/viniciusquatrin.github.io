Proyecto Confidencial

Next-Gen Service API

Arquitectura de Backend Moderna para el Ecosistema de Órdenes de Servicio

Estado: En Desarrollo

El Desafío

El sistema heredado dependía de un backend obsoleto desarrollado en Delphi, lo que dificultaba la integración con nuevas tecnologías móviles, limitaba la escalabilidad y hacía que el mantenimiento fuera extremadamente lento. El reto es crear una base sólida de microservicios que soporte la próxima generación de productos de la empresa.

SpringBoot Kotlin PostgreSQL Docker MVC Architecture

La Solución Técnica

  • • Migración de Paradigma: Implementación de una API RESTful utilizando SpringBoot con Kotlin, aplicando patrones MVC y principios SOLID para garantizar una transición robusta de lo heredado a lo moderno.
  • • Infraestructura Contenedorizada: Uso de Docker para estandarizar los entornos de desarrollo y producción, facilitando despliegues y escalabilidad horizontal.
  • • Integración entre Sistemas: Desarrollo de capas de integración para una comunicación estable entre la nueva API y aplicaciones internas, con planes futuros para la adopción de **gRPC** para comunicaciones de alto rendimiento.

Impacto Previsto

Al ser un proyecto en curso, los resultados directos en producción aún no se han medido, pero los pilares de éxito definidos son:

  • Estabilidad Superior: Eliminación de interrupciones e inestabilidades frecuentes del backend heredado.
  • Agilidad en el Desarrollo: Un entorno moderno que permite lanzamientos de funcionalidades en semanas, no meses.
  • Seguridad de Datos: Implementación de capas de autenticación y auditoría inexistentes en el sistema anterior.
