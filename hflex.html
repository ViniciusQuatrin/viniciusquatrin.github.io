Web Modernization

Hflex

Transição de Sistemas Desktop para BI e Acompanhamento Web

O Desafio

A Intelitech possuía sistemas desktop robustos, mas sentia a necessidade de oferecer aos clientes uma forma de acompanhar os dados de suas empresas de qualquer lugar. O desafio era criar uma ponte entre os dados locais (desktop) e um portal web moderno para tomada de decisão.

Ruby on Rails PostgreSQL Business Intelligence Legacy Integration

A Solução Técnica

  • • Arquitetura Web: Estruturação do backend utilizando Ruby on Rails, aproveitando a agilidade do framework para criar um sistema de portal web seguro e reativo.
  • • Integração de Dados: Criação de rotinas de sincronização e integração para que os dados gerados nos sistemas desktop fossem processados e disponibilizados dinamicamente na plataforma Hflex.
  • • Modelagem de Dados: Implementação de uma estrutura de banco de dados otimizada em PostgreSQL para suportar consultas rápidas de indicadores gerenciais.

Impacto

O projeto representou o primeiro passo da empresa em direção a soluções 100% web, criando a infraestrutura necessária para que as próximas gerações de produtos pudessem coexistir em múltiplos ambientes (Desktop e Web).
