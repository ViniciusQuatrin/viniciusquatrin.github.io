Modernização de Software Legado e Integração de Hardware Periférico

O Desafio

O sistema contava com uma base de código de mais de 11 anos, escrita inteiramente em Java. Com a evolução do ecossistema Android e as novas exigências da Google Play Store, o app apresentava diversos métodos depreciados e riscos reais de quebra em versões recentes do sistema operacional. O desafio era modernizar sem alterar a interface consolidada, para não impactar a familiaridade do usuário final.

Kotlin Java Legacy Python (Automation) View Binding Hardware Integration

A Solução Técnica

  • • Refatoração Automatizada: Para acelerar a transição de um projeto de grande escala, desenvolvi um script em Python para automatizar a substituição massiva de findViewById por View Binding, reduzindo drasticamente o erro humano e o tempo de migração.
  • • Migração Java para Kotlin: Implementei a conversão gradual e segura de classes críticas de negócio para Kotlin, garantindo a correção de bugs de nulidade inerentes à base antiga.
  • • Integração Periférica: Desenvolvi o módulo de comunicação via Protocolo de Impressão para impressoras portáteis, permitindo a emissão imediata de pedidos, notas fiscais e boletos em campo.

Impacto e Resultados

  • Extensão da Vida Útil: O software foi totalmente adequado às exigências modernas da Google SDK, garantindo mais anos de mercado.
  • Estabilidade Operacional: Correção massiva de bugs latentes e melhoria na robustez do código através do sistema de tipos do Kotlin.
  • Nova Funcionalidade Crítica: A integração com impressoras permitiu que a força de vendas operasse de forma totalmente independente e móvel.
  • Dívida Técnica Reduzida: Eliminação de componentes legados e códigos depreciados, facilitando manutenções futuras.
