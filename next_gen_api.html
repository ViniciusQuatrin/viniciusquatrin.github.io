Projeto Confidencial

Next-Gen Service API

Arquitetura de Backend Moderna para Ecossistema de Ordem de Serviço

Status: Em Desenvolvimento

O Desafio

O sistema legado dependia de um backend antiquado desenvolvido em Delphi, o que dificultava a integração com novas tecnologias móveis, limitava a escalabilidade e tornava a manutenção extremamente morosa. O desafio é criar uma base sólida de microsserviços que suporte a próxima geração de produtos da empresa.

SpringBoot Kotlin PostgreSQL Docker MVC Architecture

A Solução Técnica

  • • Migração de Paradigma: Implementação de uma API RESTful utilizando SpringBoot com Kotlin, aplicando padrões MVC e princípios SOLID para garantir que a transição do legado para o moderno seja robusta.
  • • Infraestrutura Conteinerizada: Utilização de Docker para padronizar o ambiente de desenvolvimento e produção, facilitando o deploy e a escalabilidade horizontal.
  • • Integração entre Sistemas: Desenvolvimento de camadas de integração para comunicação estável entre a nova API e aplicações internas, com planos futuros de adoção de **gRPC** para comunicação de alta performance.

Impacto Previsto

Sendo um projeto em andamento, os resultados diretos em produção ainda não foram mensurados, mas os pilares de sucesso definidos são:

  • Estabilidade Superior: Eliminação das quedas frequentes e instabilidades do backend legado.
  • Agilidade de Desenvolvimento: Um ambiente moderno que permite o lançamento de features em semanas, não meses.
  • Segurança de Dados: Implementação de camadas de autenticação e auditoria inexistentes no sistema anterior.
