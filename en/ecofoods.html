Case Study

EcoFoods

Revitalization and Integration of Payment Ecosystem for Mobile POS

The Challenge

The original application had a rigid code structure, outdated UI, and serious scalability issues. The biggest technical bottleneck was the lack of standardized integration with payment terminals (SmartPOS), requiring immense manual effort to support different acquirers such as Cielo, Getnet, and Gertec.

Kotlin Android SDK Jetpack Compose MVVM Build Flavors

The Technical Solution

I implemented a deep refactoring focused on modularization and concern separation:

  • • Payment Architecture: Used Build Flavors to isolate specific implementations of each card machine SDK. This allowed the same application core to function across distinct hardware transparently.
  • • Concurrency and Performance: Refactored data processing to use Kotlin Coroutines, managing Dispatchers to avoid UI blocking and handle critical race conditions in transactions.
  • • Modern UI: Initiated the migration of legacy XML layouts to Jetpack Compose, resulting in declarative, concise, and maintainable interface code.

Impact and Results

  • Performance Improvement: Notable reduction in app response latency and smoother navigation.
  • Visual Consistency: New interface aligned with modern UX standards, approved in internal tests.
  • Hardware Scalability: Ability to deploy to Sicoob, Getnet, Gertec, and Cielo terminals from a single unified codebase.
  • Maintainability: Cleaner code following strict MVVM, facilitating the onboarding of new developers to the project.
