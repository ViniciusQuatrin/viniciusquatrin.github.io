Confidential Project

Next-Gen Service API

Modern Backend Architecture for Service Order Ecosystem

Status: In Progress

The Challenge

The legacy system relied on an outdated backend developed in Delphi, which hindered integration with new mobile technologies, limited scalability, and made maintenance extremely time-consuming. The challenge is to create a solid microservices base that supports the company's next generation of products.

SpringBoot Kotlin PostgreSQL Docker MVC Architecture

The Technical Solution

  • • Paradigm Migration: Implementation of a RESTful API using SpringBoot with Kotlin, applying MVC patterns and SOLID principles to ensure a robust transition from legacy to modern.
  • • Containerized Infrastructure: Use of Docker to standardize development and production environments, facilitating deployment and horizontal scalability.
  • • Cross-System Integration: Development of integration layers for stable communication between the new API and internal applications, with future plans for **gRPC** adoption for high-performance communication.

Target Impact

As an ongoing project, production results are not yet measured, but the defined success pillars are:

  • Superior Stability: Elimination of frequent outages and instabilities of the legacy backend.
  • Development Agility: A modern environment that allows for feature launches in weeks, not months.
  • Data Security: Implementation of authentication and auditing layers non-existent in the previous system.
