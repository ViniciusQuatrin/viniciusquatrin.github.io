Web Modernization

Hflex

Transition from Desktop Systems to Web BI and Monitoring

The Challenge

Intelitech had robust desktop systems but felt the need to offer clients a way to track their business data from anywhere. The challenge was to create a bridge between local data (desktop) and a modern web portal for decision-making.

Ruby on Rails PostgreSQL Business Intelligence Legacy Integration

The Technical Solution

  • • Web Architecture: Structuring the backend using Ruby on Rails, leveraging the framework's agility to create a secure and reactive web portal system.
  • • Data Integration: Creation of synchronization and integration routines so that data generated in desktop systems were dynamically processed and made available on the Hflex platform.
  • • Data Modeling: Implementation of an optimized database structure in PostgreSQL to support fast management indicator queries.

Impact

The project represented the company's first step toward 100% web solutions, creating the necessary infrastructure so that future generations of products could coexist across multiple environments (Desktop and Web).
